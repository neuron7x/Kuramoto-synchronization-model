# TradePulse System Modules Overview

Огляд нових модулів системи для управління ризиками, аналізу ринку та координації агентів.

## Модулі

### 1. Adaptive Risk Manager
- VaR/CVaR розрахунки
- Адаптивні ліміти позицій
- Оцінка ринкових умов
- Інтеграція з TACL

### 2. Market Regime Analyzer
- Класифікація режимів
- Hurst exponent
- ADF тести
- Рекомендації параметрів

### 3. Dynamic Position Sizer
- Kelly Criterion
- Volatility-adjusted sizing
- Risk parity
- Adaptive methods

### 4. Agent Coordinator
- Централізована координація
- Розподіл ресурсів
- Управління задачами
- Розв'язання конфліктів

Детальну документацію див. у відповідних файлах модулів.
