# Physics Theory Contracts

This directory contains theory contracts for GeoSync invariant families.

Each contract must state:

- the mathematical object under test;
- the implementation boundary;
- the registered invariant IDs;
- allowed evidence tiers;
- tests that may promote a claim;
- conditions that keep a claim retired.

No document in this directory promotes live-market, OOS, or criticality claims without a signed audit artifact and a linked CI gate.
