# Interpretability Model

GeoSync should be readable without private context.

## Reader route

1. Start with SYSTEM_DOCUMENTATION.md.
2. Open COMPONENT_MAP.md.
3. Open MODULE_INDEX.md.
4. Open ARTIFACT_INDEX.md.
5. Open VALIDATION_MODEL.md.

## Interpretation rule

A reader should connect each named module to one input, one output, one report group and one check.

The next improvement is to add a generated table that checks these links automatically.
