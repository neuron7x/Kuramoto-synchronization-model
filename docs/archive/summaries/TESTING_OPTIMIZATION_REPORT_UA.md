**Приклад тесту:**
```python
def test_position_sizing_with_zero_balance(self) -> None:
    """Тест що розрахунок позиції обробляє нульовий баланс.
    
    Нульовий баланс повинен давати нульовий розмір позиції.
    """
    size = position_sizing(balance=0.0, risk=0.1, price=100.0)
    assert size == 0.0, "Нульовий баланс повинен давати нульовий розмір"
    assert not np.isnan(size), "Результат не повинен бути NaN"
```

#### C. Покращення існуючих тестів

**Покращено assertions з описовими повідомленнями:**

```python
# Було

# Стало
assert result > 0, (
    f"Оцінка ризику повинна бути позитивною для цієї конфігурації. "
    f"Отримано {result} з параметрами: {params}"
)
```

**Додано контекст до тестів:**
```python
def test_risk_manager_enforces_position_caps() -> None:
    """Тест що менеджер ризиків запобігає позиціям понад ліміти.
    
    Менеджер ризиків повинен застосовувати обмеження як на розмір
    позиції (кількість), так і на номінальну вартість (кількість * ціна).
    
    Валідує:
    - Обмеження позицій застосовуються на нові ордери
    - Обмеження номіналу запобігають надмірному розподілу капіталу
    - Відстеження поточної позиції точне
    - Порушення обмежень лонгу та шорту виявляються
    """
```
