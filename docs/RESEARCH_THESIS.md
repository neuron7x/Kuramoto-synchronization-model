# GeoSync Research Thesis

## Thesis

GeoSync is a falsification-first research system for measuring geometric market regimes under explicit data, graph, method, uncertainty, and evidence boundaries.

It is not a product claim surface. It is not a deployment claim surface. It is not an economic-performance assertion.

## Measurement contract

Every public research statement must trace to:

```text
claim_id -> tier -> domain -> evidence_path -> falsifier -> gate -> verdict
```

If any link is missing, the statement remains `HYPOTHESIS`, `QUARANTINED`, or `RETIRED`.

## Valid default language

```text
RESEARCH_ONLY
MEASUREMENT_SYSTEM
FALSIFICATION_FIRST
OPEN_RESEARCH_STANDARD_CANDIDATE
GEOMETRIC_REGIME_LAB
EVIDENCE_BOUND_ARCHITECTURE
```

## Scope boundary

GeoSync may measure structure. It may emit certificates. It may publish negative results. It may archive reproducible artifacts.

GeoSync must not promote structural measurements into action claims without a separate evidence path, null model, baseline comparison, cost model, ablation, and machine-readable verdict.

## v1.0 public claim target

GeoSync v1.0 may only claim:

> We define and implement a falsification-first standard for geometric market regime measurement, with explicit claim boundaries, runtime certificates, public negative results, and independently auditable artifacts.

## Stop rule

If the repository cannot trace a statement from public text back to artifact, test, data/config hash, gate, and falsifier, release language must be blocked or demoted.
