# Physics Score — Methodology, External-Validity Assessment, and Honest Relabel (RES-005)

**Verdict up front:** the GeoSync "physics score" is an **INTERNAL READINESS
RUBRIC**, not scientific validation. The **`88–92` target band is a self-set
readiness threshold**, not a scientific pass mark. The score has **no external
criterion validity**. Any surface that presents the physics score or the
`88–92` band as *scientific validation* of GeoSync's physics is a claim-firewall
contradiction (`governance/project_state.yaml`) and is blocked by
`scripts/ci/check_physics_score.py`.

This document is the de-hyping record for RES-005. It (a) traces how the score
is computed and where `88–92` lives, (b) tests it for external validity, and
(c) relabels it.

---

## (a) How the score is computed, and where `88–92` lives

**Computed by:** `tools/physics_score.py::build_score`. **Reported to:**
`VERDICT.md` (regenerated by that tool). **Current value:** `S_total = 81.5`
against target `88.0–92.0`, `FINAL_PHYSICS_VALIDATION: NO`, `MERGE_READY: NO`.

**Where `88–92` is stated (inventory):**

| Location | Statement |
|---|---|
| `tools/physics_score.py` | `TARGET_INTERVAL = [88.0, 92.0]` — a hardcoded constant |
| `VERDICT.md` | `Target interval: 88.0-92.0`, `TARGET: 88-92` |
| `docs/audit/nfi_physics_validation_protocol_v3.md` | "Target score: 88-92 after machine-computed scoring" |
| `docs/audit/nfi_operationalization_matrix_v3.md` (M012) | "S_total in target interval 88-92" |
| `docs/audit/claim_ledger.md` (CLM-SCORE-001) | "Repository has physical score 88-92" → status `UNDEFINED` |
| `docs/physics/geosync_core.md` | "GeoSync physical rank is 88-92" → `FORBIDDEN` |
| `docs/audit/2026-06-physics-depth-external-audit.md` | external audit already flags `81.5` vs `88–92` and the hardcoded interval |

The band is a **constant chosen by the author**, not a value derived from a
measurement procedure. `S_total >= TARGET_INTERVAL[0] and not blockers` is the
only place it is consumed.

**Composite structure** (`tools/physics_score.py::build_metrics`, 10 components,
weights sum to `1.0`):

| Component | Weight | Score | How the number is produced |
|---|---:|---:|---|
| `S_math_object` | 0.12 | 75.0 | literal `75.0` if carrier files exist, else `0.0` |
| `S_dimensional_consistency` | 0.10 | 70.0 | literal `70.0` if units doc + dim test exist, else `0.0` |
| `S_numerical_stability` | 0.12 | 86.0 | literal switched `86 / 82 / 0` by CI + file presence |
| `S_invariant_preservation` | 0.12 | 88.0 | literal switched `88 / 80 / 0` |
| `S_falsifiability` | 0.14 | 86.0 | literal switched `86 / 82 / 0` |
| `S_baseline_models` | 0.10 | 85.0 | literal switched `85 / 82 / 0` |
| `S_UQ` | 0.08 | 74.0 | literal switched `74 / 72 / 0` |
| `S_reproducibility` | 0.08 | 83.0 | literal switched `83 / 78 / 0` |
| `S_interface_contracts` | 0.08 | 78.0 | literal switched `78 / 70 / 0` |
| `S_traceability` | 0.06 | 88.0 | literal `88.0` if ledger + inventory + traceability exist |

**Traceability finding (the crux):** *every* component score is an **editorial
constant** toggled by the **presence/absence of carrier files and CI-evidence
booleans**. Not one component is a continuous measurement against a physical
ground truth. `S_dimensional_consistency = 70.0 (PARTIAL_PASS_NO_TYPED_UNITS)`
is emblematic — the tool's own status admits there is no typed-units check
behind the number. So the aggregate measures **"are the expected invariant/test/
CI carriers present?"** — a coverage checklist — and dresses that coverage in a
two-decimal number that *reads like a measurement*.

Per-component traceability (id → weight → measurement function → evidence
carriers → the editorial-vs-measured classification) is recorded in
`artifacts/research/physics_score_calibration.json`.

## (b) External-validity assessment

Four questions decide whether a composite number is scientific validation:

1. **Is there an external criterion the score predicts?**
   **No.** The repo is `RESEARCH_ALPHA`, synthetic-only, `NO_DEPLOY`
   (`governance/project_state.yaml`, `PRODUCT_CATEGORY.md`). There is no market
   outcome, no independent replication, no held-out ground truth. There is
   **nothing to correlate the score against** — criterion validity is
   **UNDEFINED**, not merely low. The score's own evidence class is
   `SIMULATION`, and per the claim firewall `SIMULATION` can back neither
   `validated` nor `proven`.

2. **Is there a weighting rationale?**
   **None is stated.** The ten weights (`0.12, 0.10, …, 0.06`) are asserted in
   source with no derivation from importance, variance, or a decision model.

3. **Is the score sensitive to the weights?** See (d) — it is **robust** to
   weights but that does not rescue validity; it exposes a different
   arbitrariness (the band sits above the reachable range).

4. **Is it calibrated against any ground truth?**
   **No.** There is no dataset, no labels, no reference score. "Calibration"
   here means only that literals were hand-set to sum near a chosen number.

**Conclusion:** external criterion validity **cannot be shown** and, given the
synthetic-only boundary, **cannot in principle exist** for this score in its
current form. This is the expected outcome, not a defect to be patched with more
components.

## (c) Relabel

- The physics score is an **INTERNAL READINESS RUBRIC**: a weighted
  self-assessment of invariant/test/CI **coverage** over GeoSync's own
  computation.
- It is **explicitly NOT scientific validation** of GeoSync's physics against
  the world.
- **`88–92` is a self-set readiness threshold**, not a scientific criterion.
  Reaching it would mean "the expected carriers and CI evidence are present at
  the author's chosen coverage bar" — an internal go/no-go, nothing about
  external truth.
- **External-validity gap (stated, not hidden):** no external criterion, no
  independent replication, no ground-truth calibration. Closing this gap
  requires real-data `MEASURED` evidence with provenance and a null baseline —
  which the `RESEARCH_ALPHA` boundary does not currently permit.

The pre-existing controls that *already* treat "physical rank 88–92" as
`FORBIDDEN` / `UNDEFINED` (`docs/physics/geosync_core.md`,
`docs/audit/claim_ledger.md`) are consistent with this relabel; RES-005 makes
the rubric-not-validation status explicit and machine-enforced.

## (d) Weight-sensitivity result

Reproducing the component literals from `VERDICT.md` and renormalizing under
perturbed weight vectors (full numbers in
`artifacts/research/physics_score_calibration.json`):

| Perturbation | Score | Δ vs authored (81.5) |
|---|---:|---:|
| Authored weights | 81.5 | — |
| Equal weights (0.10 each) | 81.3 | −0.2 |
| Double any single weight (max over 10) | — | ±1.05 |
| Random weights, Dirichlet(1), N=20000 | mean 81.3, sd 1.85 | p05 78.1 / p95 84.2 |

**Two findings:**

1. **The score is robust to the weights** (sd 1.85; equal-weights moves it
   0.2). So the *weighting* is not the main arbitrary lever — the tight cluster
   of hand-set component literals dominates the aggregate.

2. **The `88–92` band is unreachable and disconnected from the measurement.**
   In `0 of 20000` random weightings does the score enter `88–92`. The **maximum
   score attainable under any weighting is `88.0`** — the ceiling of the single
   highest component. The target band floats **above the entire reachable
   range**. A pass mark you cannot reach by any weighting of the current
   evidence is a self-set aspiration, not a measured criterion.

Net: robustness to weights does **not** confer validity. The arbitrariness is
in the **editorial component literals** and in a **target band placed above what
the components can produce**. Both confirm the relabel: internal readiness
rubric, not scientific validation.
