# Criticality FSS Boundary

Status: NOT_RUN.

This directory is a preregistration boundary, not evidence.

A future promotion of the retired criticality claim requires:

- R_N(K) for N in 8, 16, 32, 64, 128;
- susceptibility chi_N(K) = N * Var(R);
- K_c(N) estimation;
- declared scaling-collapse diagnostics;
- null comparisons against shuffled, IAAFT, ARMA or GARCH surrogates when applicable;
- a machine-readable result artifact with config hash, data hash, seeds, pass flags, and claim status.

Until a validated result exists, docs must keep criticality in retired or hypothesis status.
