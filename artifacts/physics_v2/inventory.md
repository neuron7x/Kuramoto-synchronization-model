# Physics v2 — P0 Inventory & Boundary Audit

Status: **first-slice inventory (P0)**
Branch: `docs-physics-v2-manifold-spec` · PR #1284
Generated by: Claude Code, per `docs/architecture/physics_v2_universal_synchronization_manifold.md` §2 P0
Scope: read-only audit of existing surfaces. No solver, no L2 ingest, no market claim.

> **Headline finding.** GeoSync is far more built-out than the architecture handoff
> assumes. The four negative controls of P5 (`core/kuramoto/falsification.py`), the
> evidence capsule of P6 (`instrument_validation/capsule.py`), the 14-rung claim ladder
> (`analytics/signals/claim_maturity.py`), the L2 schema, and a full Ricci/Kuramoto
> stack **already exist**. The genuine gap is *not* another physics subsystem — it is a
> thin **typed contract layer** that binds these pieces into one replayable
> `snapshot → frame → comparison → capsule` chain. This first PR adds only that layer
> plus draft laws; it duplicates nothing.

The audit verdict per module uses three tags:

- **REUSE** — exists and is fit for purpose; Physics v2 must build on it, not fork it.
- **EXTEND** — exists but needs a thin typed wrapper or one new field.
- **MISSING** — no equivalent exists; this first PR (or a later one) introduces it.

**Synchronization-manifold frame (P4) verdict: EXTEND.** Order parameter, phase
dispersion (via `chimera_index`), finite-size floor (ε=3/√N), and regime labels all
exist but are *scattered*. Missing is a single typed `SynchronizationManifoldFrame`

real solver is deferred (architecture doc §4: "Do not merge P4 before P2/P3").

**Falsification battery (P5) verdict: REUSE — already complete.** The four required

(`time_shuffle_test`, `iaaft_surrogate_test`, `degree_preserving_rewire`,
counterfactual perturbations). Physics v2 must call these; `ComparisonReport` in this
PR is the typed *container* for their verdicts, not a re-implementation.

**Causal-graph snapshot (P2) verdict: MISSING → shipped here.** No typed
`MarketCausalGraphSnapshot` exists (the closest, `temporal_ricci.GraphSnapshot`, is a
single-asset price-level descriptor, not a multi-asset causal graph with latency

`physics_contracts/manifold/contracts.py::MarketCausalGraphSnapshot` with fail-closed

single chokepoint that turns an absent licensed dataset into an explicit
`DATA_UNAVAILABLE` verdict. This PR ships `require_licensed_l2` / `resolve_data_status`
(rejects `None`, zero-hash, and `synthetic:`-tagged fingerprints; never substitutes
synthetic data). This is architecture doc §3's hard rule.

## 6. What this first PR adds (and explicitly does NOT)

**Adds** (P0–P1 + typed scaffolds for P2/P4/P5/P6, no solver):

1. this inventory artifact;
2. 6 draft (`warn`) candidate laws in `physics_contracts/catalog.yaml`;
3. typed `MarketCausalGraphSnapshot` (P2 schema) with fail-closed validation;
4. `CurvatureSyncFrame` (P4 schema), `ComparisonReport` (P5 container),
   `EvidenceCapsuleShape` (P6 shape);
5. deterministic synthetic fixtures + 25 synthetic tests;
6. fail-closed `require_licensed_l2` (explicit `DATA_UNAVAILABLE`, never synthetic
   substitution);
7. a valid commit-acceptor binding the slice.

**Does NOT** (deferred or forbidden by architecture doc §5):

- no numerical Ricci-flow solver (P3) — reuses `core/kuramoto/ricci_flow.py` later;
- no L2→graph builder / real ingestion — deferred to P2 implementation PR;
- no predictive-alpha, production-trading, universal-market-physics, or
  relativity-equivalence claim;
- no real-L2 claim — there is no dataset manifest, data hash, or run artifact in this
  slice, and the capsule shape fails closed if one is asserted.

**Fixed invariant (architecture doc §8).** No physical market claim may enter the repo
unless its validity domain, falsifier, witness, and provenance capsule are present in the
same reviewable chain. This PR introduces the *typed vocabulary* for that chain and
asserts nothing beyond synthetic-fixture determinism.
