# Glossary

## Intent
Definition: the actionable aim behind input.
Non-definition: a mood or identity claim.
Input signal: request, constraint, desired output.
Output signal: objective and next action.
Failure mode: vague goal.
Example: turn a noisy note into a task.

## Artifact
Definition: an inspectable output that can be reviewed or tested.
Non-definition: private certainty.
Input signal: method result.
Output signal: file, report, schema, or decision.
Failure mode: prose with no action.
Example: a JSON report.

## Validation
Definition: a check that compares output to a contract.
Non-definition: approval by tone.
Input signal: artifact and rule.
Output signal: pass, partial, blocked, or failed.
Failure mode: missing evidence.
Example: schema parse succeeds.
