# Cognitive Mirror Methods

Cognitive Mirror Methods is a practical toolkit for structured reflection, introspection, reverse inference, extrapolated thinking, language expansion, and insight-to-artifact conversion with LLMs.

It is not AGI, not consciousness work, not therapy, and not medical advice.

## Core thesis

Language shapes attention. Attention shapes internal models. Internal models shape decisions. LLM mirrors can expose those models. Structured protocols convert reflection into artifacts. Artifacts make thinking testable.

## Execution contract

Every method has an input, process, output, validation rule, failure mode, and example. Every production prompt is versioned. Every machine-facing output must be schema-compatible.
